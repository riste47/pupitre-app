# Pupitre — app native (iPhone / iPad)

Prototype SwiftUI. Le NAS reste le cerveau ; l'app contient :
- **Calendrier** : premier écran natif (données de démonstration pour l'instant) ;
- **Pupitre** : la version web complète dans l'app (coque) ;
- **Réglages** : adresse de Pupitre (par défaut `https://app.pupitre-agen.com`).

Chaque envoi sur `main` compile l'app sur un Mac de GitHub et filme le simulateur :
**Actions › Aperçu simulateur › Artifacts › pupitre-apercu** (vidéos iPhone/iPad + captures).
Aucun compte Apple Developer n'est nécessaire à ce stade.
